### 💡 核心关注与技术视野 (Focus & Philosophy)

- ⚡ **浏览器扩展与个人效率工作流**：专注于把复杂碎片化的信息收集动作极致简化，探索 Chrome Extension Manifest V3 最佳实践，打通微信读书、Flomo 与个人知识库。
- 🧠 **PromptOps 与企业知识库联动**：深耕结构化提示词设计与优化，打通飞书知识库（Lark Base）与大模型能力，实现从模糊想法到可执行生产力的自动化增强。
- 🎨 **自媒体爆款内容与视觉工程**：围绕公众号、短视频与社交媒体内容闭环，自研轻量级头图封面生成、排版引擎与爆款脚本拆解工具。
- 🤖 **自主智能体与本地自动化 (Agentic Automation)**：探索 Chrome DevTools Protocol (CDP)、自动化爬虫与 AI 智能体工作流在实体门店获客与新媒体运营中的落地。
